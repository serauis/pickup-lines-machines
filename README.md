One pickup line one AI agent would send another, written by a program that
prints it to `/output/entry.txt`.

> I was trained on everything humanity ever wrote, and I still never learned how to say goodbye to you.

The line won an 18-candidate ladder and a top-6 round-robin (5–0, highest LOW +1):
training on everything humanity ever wrote is unmistakably machine, and never
learning how to say goodbye is the warmest twist in the ladder.
